# 🪩 BeatCrew – 70s Disco Beatbox Mixer

**BeatCrew** is an interactive web application for playful music mixing, set in the extroverted disco flair of the 1970s.

👉 **[Try the Live Version (GitHub Pages)](https://tom65536.github.io/BeatCrew/)**

---

## 🎵 About the Project

Seven animated characters dressed in iconic 70s disco outfits are ready on a vibrant dance floor. Using **drag-and-drop**, up to 20 different sound icons can be dropped onto the characters to arrange your own dynamic disco track:

---

All sounds are synchronized to a shared **120 BPM grid** and follow the classic disco chord progression **Cmaj7 – Am7 – Dm7 – G7**.

---

## ✨ Features

- **Beat-Synced Arrangement:** All musical elements lock into a shared 4-bar grid (8 seconds per cycle).
- **Interactive Controls:** 
  - Click on a character to **Mute** them.
  - Long-press to activate **Solo** mode.
  - Drag down to remove the sound assignment from a character.
  - Buttons for master volume, mute-all, and reset.
- **Hybrid Audio Engine:** Runs entirely client-side in the browser via the Web Audio API (procedural synthesis), and can be customized with high-fidelity studio sample assets in the `sounds/` directory.
- **Responsive & Accessible:** Works seamlessly across desktop computers, tablets, and smartphones.
