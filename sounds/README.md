# BeatCrew Sound Asset Guide 🎶

In diesem Ordner können eigene Audio-Dateien (Loops oder One-Shots) abgelegt werden.
Sobald eine Datei hier mit dem passenden Namen existiert, schaltet BeatCrew automatisch vom internen Synthesizer auf dein Studio-Sample um!

---

## 1. Loop-Spezifikationen
* **Tempo:** Exakt **120 BPM**
* **Tonart:** Passend zu **C-Dur / A-Moll** (Akkordfolge: `Cmaj7` – `Am7` – `Dm7` – `G7`)
* **Länge:**
  * **1 Takt (4 Beats):** genau **2,000 Sekunden**
  * **4 Takte (16 Beats):** genau **8,000 Sekunden**
* **Formate:** `.mp3`, `.wav` oder `.ogg` (alle drei werden automatisch erkannt)
